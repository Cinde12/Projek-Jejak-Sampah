# Jejak Sampah (versi gratis)

Flutter + Firebase Auth + Cloud Firestore + Cloudinary (foto).
Fitur perangkat: Kamera + GPS. Peta: OpenStreetMap.

Isi lib/utils/config.dart dengan Cloud name dan Upload preset Cloudinary,
tempel firebase/firestore.rules di Firestore, lalu jalankan `flutterfire configure`
dan `flutter run`. Panduan lengkap ada di jawaban chat.
